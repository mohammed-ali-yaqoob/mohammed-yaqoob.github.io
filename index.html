نبذة تعريفية

مطور برمجيات مقيم في تريم، حضرموت. أدرس تقنية المعلومات (تخصص تطوير البرمجيات) في كلية الحاسبات بجامعة سيئون. أركز على بناء وتطوير تطبيقات الهواتف الذكية متعددة المنصات باستخدام إطار العمل Flutter، بالإضافة إلى تصميم وتطوير أنظمة سطح المكتب الإدارية والهندسية المتكاملة باستخدام C# وقواعد البيانات.

المهارات التقنية

Flutter & Dart C# (WinForms) C++ Java HTML / CSS / JavaScript SQL & SQLite Oracle Database Software Engineering Linux & Technical Support

أبرز المشاريع البرمجية

نظام إدارة المكاتب الهندسية والاستشارات

نظام مكتبي متكامل مبني بلغة C# وقاعدة بيانات SQLite لإدارة المشاريع الهندسية، بيانات العملاء، ومتابعة العقود، صُمم خصيصاً لتلبية احتياجات المكاتب الهندسية مثل مكتب الإنجاز للهندسة.

تطبيق إدارة المدارس ومتابعة الطلاب

تطبيق هاتف محمول مطور باستخدام Flutter و Dart يتيح لأولياء الأمور متابعة حضور الطلاب، الدرجات، الجداول الدراسية، والواجبات اليومية.

نظام إدارة المتدربين (Trainee Management System)

تطبيق سطح مكتب بواجهات C# WinForms مربوط بقاعدة بيانات SQLite لإدارة بيانات المتدربين وسجلاتهم بكفاءة.
